## 產生方式（build/）

網站是用 Python 腳本產生的：
- `content.py`：舊網站原文（已修錯字）
- `build2.py`：資料（由來、堂主、最新消息、文章、影片、年度行事、殿堂）
- `build3.py`：v1 版面和共用元件，輸出到 `web3/`
- `build3b.py`：用 `content.py` 的原文覆蓋各頁內容

執行：在暫存資料夾裡放 `_dev/build/` 的檔案，加上一個 `web3/`（內容 = repo 根目錄的網站檔案），跑 `python3 build3b.py`，再把 `web3/` 裡的 HTML 複製回 repo 根目錄。
